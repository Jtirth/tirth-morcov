PROJECT OVERVIEW

Predictive text, made explainable.

NextWord Lab is a Probability and Statistics learning project that shows how word transitions and conditional probability can create next-word predictions without neural networks or paid APIs.

How it works

The included sample training corpus is normalized into lowercase word tokens. The application counts single words, adjacent word pairs, and three-word sequences. For a given context, candidate continuations are ranked by their observed frequency. Each displayed probability is the continuation count divided by the total observed transitions from that context.

Two Markov models

The first-order model uses one preceding word. The second-order model uses the previous two words. A longer context can be more specific, but it is observed less often in a small corpus. This is a frequency-based Markov chain, not a neural language model and it does not understand meaning.

Dataset integrity

The small, original demonstration corpus exists to make repeated patterns easy to inspect. It does not represent everyday English or real-world language frequencies. Training and testing examples are stored in separate files. Comparison metrics are computed against held-out test tokens; coverage is reported separately, and top-k accuracy is conditional on a context being present in training.

Custom training

Paste your own text in the dashboard to rebuild counts in server memory. The custom training is temporary: it is not saved to disk, shared with other users, or preserved after the server restarts. Use non-sensitive text only.
